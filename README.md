# WikiTree Prize Draw

WikiTree Marathon Drawing is a browser-based live host tool for drawing winners during WikiTree marathons and other events. Hosts can manage the shared ineligible list, spin bibs or balls to pick random winners, and generate ready-to-paste WikiTree prize tables without needing a server or any backend setup.

**Live page:** https://robinson27225.github.io/wikitree-prize-draw/

Everything runs in the browser. There is no server to maintain. The only outside pieces are WikiTree (the random tool and the bib images) and a Google Apps Script that lives in the participants spreadsheet and syncs the ineligible list.
